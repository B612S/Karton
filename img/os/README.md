# OS icons

Flat family icons used by the VM list. The Linux (Tux), BSD family, macOS and
DOS icons are derived from the Papirus icon theme (GPL-3.0-or-later); the
Windows icons are simple flat flags drawn for Karton. All icons use a
transparent canvas and contain no outer tile or background.

`karton-os-generic.svg` is Karton's own fallback for an unknown guest OS. It is
a monitor with a question mark rather than the plain symbolic monitor. The
Linux New Year variant adds a snow drift under Tux and is used around
25 December through 7 January.
